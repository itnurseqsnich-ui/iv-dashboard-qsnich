เชื่อมต่อผ่าน Apps Script Web App URL

🔒 ลิงก์นี้ฝังไว้ในไฟล์แล้ว — ถ้าเปลี่ยน Apps Script deployment ใหม่ (URL เปลี่ยน) ค่อยมาแก้ตรงนี้ทีหลัง
วิธีนี้ปลอดภัยที่สุด — ชีตต้นฉบับไม่ต้องเปิดสาธารณะเลย เพราะ Apps Script จะส่งกลับเฉพาะตัวเลขสรุป ไม่มีชื่อผู้ป่วย

เชื่อมต่อ Google Sheets

เปิดสิทธิ์แชร์ Sheet เป็น "ทุกคนที่มีลิงก์ - ดูได้" ก่อน แล้ววางลิงก์เต็มของ Sheet ที่นี่ (ระบบจะดึง Sheet ID ให้อัตโนมัติ)

วางข้อมูลสรุป (CSV) — คอลัมน์: ปีงบประมาณ, เดือน, Ward, Site, Phlebitis, Infiltration, Extravasation

วางข้อมูลดิบ (CSV) — ต้องมีคอลัมน์: ยาตัวที่ 1-4 ที่ผู้ป่วยได้รับก่อนเกิด IV Complication, สารน้ำที่ได้รับก่อนเกิด IV Complication
